# Офлайн-словарь для Ізден (школьники 7–9 классов, Казахстан)

Ученик нажимает слово в тексте и видит перевод. Нужно перевести списки словоформ, взятых из учебных текстов
(расписания, объявления акимата, задачи про ферму, цены, проценты, площадь).

## Вход и выход
`todo_<lang>_<NN>.txt` — по одной словоформе в строке, в нижнем регистре (`ё` заменена на `е`).
- `todo_ru_*` — русские слова → перевод на **казахский**.
- `todo_kk_*` — казахские слова → перевод на **русский**.

Для каждого входного файла запиши `done_<lang>_<NN>.json` (тот же lang и номер) в эту же папку — один JSON-объект:
```json
{"ауылының": ["ауыл", "село"], "беріледі": ["беру", "давать"], "райцентр": ["райцентр", "аудан орталығы"]}
```
- ключ — словоформа ТОЧНО как во входном файле (все строки файла должны быть ключами);
- первый элемент — начальная (словарная) форма на языке оригинала: им. падеж ед. ч. для существительных,
  инфинитив для глаголов (в казахском — корень/основа глагола: «беру», «келу»), м. р. ед. ч. для прилагательных;
- второй — перевод начальной формы на другой язык, 1–3 слова, самое частое школьное значение. Без пояснений в скобках,
  кроме имён собственных.
- Имена людей и названия сёл/компаний: перевод = то же имя в другом написании + пометка, например
  `"көктөбе": ["Көктөбе", "Коктобе (село)"]`, `"айгерим": ["Айгерим", "Айгерім (есім)"]`.
- Служебные слова и частицы тоже переводи (`"и": ["и", "және"]`, `"мен": ["мен", "и; с"]`).
- Обрывки слов, аббревиатуры: переводи как есть (`"ден"` — `["-ден", "от, с (окончание)"]`).

Пиши файл через python (json.dump(..., ensure_ascii=False)), не вручную. Проверь, что число ключей равно числу строк
входного файла и все ключи совпадают. Не трогай другие файлы проекта.
