# Ізден — сценарий питч-видео (≤ 3:00)

Черновое видео `pitch.mp4` (2:48) собрано по этому сценарию: голос macOS Milena, запись демо с прода (https://izden.vercel.app) в Playwright, телефон 390×844 внутри кадра 1920×1080, между фрагментами — слайды. Команде лучше переозвучить своими голосами: текст ниже можно читать как есть (367 слов, ~130–135 слов в минуту).

История: **угадал → докажи → учитель видит ловушку класса → приём на завтра → печатный лист**, всё в режиме полёта. Демо на казахском (Айгерім, 8 сынып), русский — переключатель в конце демо. Казахские надписи экрана продублированы справа от телефона.

## Если после пилота есть данные

Блок «Доказательства» (2:05–2:26) заменить последней фразой на данные пилота, не удлиняя видео:

> «На пилоте {ПИЛОТ: N учеников} {ДОЛЯ}% ответов были верными без доказательства — обычный тест засчитал бы их как понимание. Учитель сказал: {ЦИТАТА учителя}.»

И вернуть плейсхолдер пилота на слайд 7 (в `slides.html` он есть, в видео скрыт).

## Как пересобрать

```bash
cd submission
DSF=2 python3 tools/record_demo.py && mv build/shots build/shots_hi   # скриншоты для слайдов
python3 tools/record_demo.py                                          # запись видео (DSF=1)
python3 tools/build_slides.py                                         # slides.html, slides.pdf, кадры слайдов
python3 tools/make_video.py                                           # озвучка + склейка → pitch.mp4
```
Нужны Playwright (Chromium), `~/.local/bin/ffmpeg`, macOS `say`. Учительский телефон сканирует QR через виртуальную камеру Chromium (`--use-file-for-fake-video-capture`); если камера не сработает, скрипт вводит короткий код.
