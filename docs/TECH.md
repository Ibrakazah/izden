# Ізден: техническое описание

Для тех, кто хочет проверить код. Обзор для жюри — в `README.md`.

## Запуск и проверки

```bash
python3 -m http.server 8000        # из корня проекта, открыть http://localhost:8000
```

Нужен только Python 3 (без зависимостей); тесты JS-части запускают код в JavaScriptCore через `osascript` (macOS) и падают, если его нет.

```bash
python3 scripts/check.py           # схема банков, ровно один верный, evidence не на заголовках, подсказки по форме
                                   # вариантов, версия кэша sw.js, нет внешних URL
python3 scripts/check.py --stamp   # перед деплоем: версия кэша sw.js = хэш всех кэшируемых файлов
python3 tests/test_engine.py       # JS- и Python-движок совпадают до 1e-9 на одном сценарии (--update обновляет эталон)
python3 tests/test_text.py         # разбиение на предложения и перемешивание вариантов одинаковы в JS и Python
python3 tests/test_qr.py           # QR-строка и короткий код: туда-обратно, опечатки и перестановки отклоняются
python3 scripts/option_stats.py    # как часто «угадывающие» стратегии находят ключ (по длине вариантов)
python3 evals/simulate.py          # 500 синтетических учеников → evals/bkt_report.md
python3 evals/ai_students/calibrate.py && python3 scripts/build_bank.py && python3 scripts/build_passport.py
```

Деплой — любая статика. `vercel.json` отдаёт `sw.js` с `Cache-Control: no-cache`; `check.py` падает, если версия кэша не соответствует файлам, поэтому у пользователей не остаётся старый код.

## Модель навыков (Bayesian Knowledge Tracing)

- Три навыка = три процесса PISA: найти (locate), понять (understand), оценить (evaluate). Для каждого хранится вероятность владения p.
- На вопрос два наблюдения: ответ и отмеченное доказательство. Правдоподобия: знает — (1 − slip) и (1 − evidence_miss); не знает — guess и evidence_guess. Затем переход обучения p_learn. Верный ответ без доказательства — слабое свидетельство (p 0,30 → 0,38 против 0,62 с доказательством).
- Учитывается только первая попытка; запись о вопросе хранится в сессии, поэтому перезагрузка или уход на другой экран не засчитывают ответ повторно и возвращают в ту же фазу (вторая попытка, «докажи»). Подсветка доказательства после ошибки — только по кнопке или после второй ошибки, и отмечается «с помощью».
- Следующий текст: максимум Σ(1 − p)² × близость сложности вопроса к уровню навыка, штраф за другой класс и за повтор; вопросы по освоенным навыкам (p ≥ 0,85) пропускаются (минимум 2 на текст).
- slip/guess и параметры доказательства откалиброваны по ИИ-ученикам (`evals/ai_students_report.md`), p_init/p_learn — априорные. `evals/engine.py` — построчная копия `js/engine.js`.

## Банк заданий

- `data/bank.<lang>.json`, контракт — `docs/PLAN.md`. Evidence: предложение (`b3:s2`), строка таблицы (`b2:r3`), пункт списка (`b5:i1`), столбик диаграммы; ссылки на заголовки запрещены (их нельзя нажать).
- Предложения делятся одним правилом в JS и Python (после `. ! ? …` и пробела).
- Варианты показываются в детерминированно перемешанном порядке: FNV-1a от «unit/question» → mulberry32 → Фишер–Йейтс (`js/text.js` = `scripts/shuffle.py`). Печатный лист — отдельный документ: верные ответы распределяются по A–D блоками по 4, ключ листа совпадает с листом.
- Подсказки по форме: `scripts/option_stats.py` считает, как часто ключ находят стратегии «самый длинный», «второй по длине», «самый короткий», «ближе к средней длине»; каждая и каждый ранг длины верного ≤ 35%, иначе `check.py` падает.

## Передача учителю

- QR: `IZ1|инициалы#метка|класс|язык|p×3|попытки×3|верно×3|ловушки×6|диагнозы×4|текстов|дата|показы ловушек×6|контрольная сумма` — около 90 байт, UTF-8.
- Короткий код без камеры: 16 символов (Crockford base32), 75 бит данных + контрольный символ Luhn mod 32: ловит все одиночные опечатки и соседние перестановки; код без ответов отклоняется.
- Метрика ловушки в отчёте класса: ошибочные ответы в эту ловушку / все ответы класса на вопросы, где она была среди вариантов («показы» приходят в QR; для учеников, добавленных коротким кодом, оцениваются по доле таких вопросов в банке и помечаются).
