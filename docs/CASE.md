# Кейс 3. Образование: читать и понимать

Дословно из документа организаторов (t.me/orleyhack, 25.11.2026). Решать можно как угодно: «как её решать, команда решает сама».


## Контекст
В PISA-2025 участвовали 22 680 казахстанских школьников в возрасте 15 лет из 643 организаций образования (Azattyq Ruhy). Базового второго уровня достигли 52% по естествознанию, 44% по математике и 36% по чтению (BES.media). В среднем по ОЭСР по естествознанию этот уровень у 74% (Forbes Kazakhstan).
Иными словами, двое из трёх 15-летних не могут найти нужную информацию в тексте средней сложности и сделать из неё вывод. Разрыв между городскими и сельскими школами по математике в PISA-2022 составлял 18 баллов (Казахстанская правда).
